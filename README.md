# NIKO AI

**NIKO** مساعد شخصي ذكي متعدد اللغات، يهدف إلى فهم المستخدم والتفاعل معه بالصوت والنص ومساعدته في تنفيذ المهام اليومية عبر مهارات قابلة للتوسّع.

> **حالة المشروع:** مرحلة التأسيس والتوثيق. لا توجد نسخة تطبيق أو خدمة منشورة حتى الآن.

## الرؤية
بناء مساعد يتكيّف مع لغة المستخدم ولهجته، ويفهم المزج بين اللغات، ويخطط للمهام وينفذ ما تسمح به المنصة والصلاحيات، مع حماية الخصوصية وطلب الموافقة قبل الإجراءات الحساسة.

## مبادئ المشروع
- **مجاني أولاً:** حلول مفتوحة المصدر ومحلية ومجانية قدر الإمكان، دون افتراض أن API أو الاستضافة أو النشر مجانية.
- **متعدد اللغات:** العربية بلهجاتها، والإنجليزية، والتركية، مع فهم التبديل والمزج بينها.
- **يتكيّف مع المستخدم:** يرد باللغة واللهجة اللتين يستخدمهما الشخص تلقائياً.
- **آمن وتحت السيطرة:** موافقة قبل الإرسال أو النشر أو الشراء أو الحجز أو الاتصال أو حذف البيانات.
- **قابل للتوسّع:** مهارات مستقلة ومزودو نماذج قابلون للاستبدال.
- **واقعي تقنياً:** احترام قيود iOS وAndroid وسياسات الخدمات الخارجية.

## سياسة التكلفة والقيود
الهدف هو جعل التطوير والتشغيل بلا تكلفة قدر الإمكان، لكن بعض المتطلبات لا يمكن ضمانها مجاناً أو في الخلفية على جميع الأجهزة. من أمثلتها الاستماع الدائم إلى كلمة تنبيه مخصصة على iPhone، وتشغيل نماذج كبيرة، ومكالمات الهاتف، وواجهات WhatsApp ووسائل التواصل، ورسوم متاجر التطبيقات. ستوثّق البدائل والقيود قبل اعتماد أي ميزة.

## حالة التنفيذ
الموجود حالياً وثائق تأسيسية وهيكل مجلدات فقط. لم يبدأ تنفيذ كود التطبيق. لا تُعتبر أي ميزة مكتملة لمجرد ورودها في الوثائق.
