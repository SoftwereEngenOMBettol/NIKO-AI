# NIKO AI

**NIKO** مساعد شخصي متعدد اللغات والوسائط والمهارات، يُطوّر للـ **iPhone أولاً** مع إبقاء Android هدفاً تالياً من قاعدة Flutter مشتركة.

> **الحالة الحالية:** نموذج أولي قيد التطوير. توجد واجهة Flutter واتصال محلي بـ Ollama، وأُضيف في فرع التكافؤ أساس أولي لتوليد مستندات Office والنصوص واكتشاف القدرات. لا تزال الصور والفيديو والبحث والنشر والتكاملات الخارجية غير مفعّلة.

## الرؤية

بناء مساعد شخصي بمستوى قدرات Tab AI: يفهم النص والصوت والصور والملفات، ويخطط وينفذ مهاماً متعددة الخطوات، وينشئ الصور والفيديو والمستندات، ويُنجز الأعمال عبر تكاملات رسمية. لا تُعلن أي ميزة جاهزة إلا بعد اختبارها فعلياً.

## قرار المنصات

- **الأولوية الأولى: iOS وiPhone 13 وما بعده.** تُتخذ قرارات تجربة الاستخدام والصوت والخصوصية والاختبار وفق احتياجات iOS أولاً.
- **الأولوية التالية: Android.** نحافظ على التوافق بقاعدة Flutter نفسها، ونؤجل تحسينات Android الخاصة إلى مرحلة لاحقة.
- التطوير اليومي يمكن أن يستمر على Windows، لكن بناء iOS واختباره عبر Xcode يتطلب macOS. GitHub Actions على macOS يستطيع فحص بناء المحاكي، لكنه لا يغني عن اختبار iPhone حقيقي أو التوقيع والتوزيع.

## مبادئ المشروع

- **iPhone أولاً:** احترام قيود الخلفية والميكروفون والإشعارات والصلاحيات.
- **مجاني أولاً:** حلول مفتوحة المصدر ومحلية قدر الإمكان؛ لا نفترض أن API أو الاستضافة أو التوليد عالي الجودة مجاني أو غير محدود.
- **متعدد اللغات:** العربية بلهجاتها، والإنجليزية، والتركية، مع فهم المزج بينها.
- **استقلالية مسؤولة:** تنفيذ المهام الآمنة دون أوامر تقنية متكررة، وطلب موافقة قبل الإرسال أو النشر أو الشراء أو الحجز أو الاتصال أو حذف البيانات.
- **قابل للتوسّع:** مهارات مستقلة ومزودو نماذج قابلون للاستبدال.
- **واقعي تقنياً:** لا نعرض نتائج وهمية ولا ندّعي تشغيل خدمة قبل تهيئتها واختبارها.

## الوحدات

- `mobile/` — تطبيق Flutter للهاتف.
- `backend/` — واجهات NIKO وخدمات المستندات.
- `ai-engine/` — طبقة الذكاء والتخطيط وتوجيه النماذج (قيد التطوير).
- `skills/` — مهارات NIKO القابلة للإضافة (قيد التطوير).

## الحالة التنفيذية

- تطبيق Flutter أولي مع واجهة محادثة وحفظ محلي وتفضيل لغة.
- Backend محلي متصل بـ Ollama للمحادثة.
- في فرع `feat/tab-ai-parity-foundation`: نقطة `GET /v1/capabilities` لعرض الحالة الفعلية للميزات.
- في الفرع نفسه: `POST /v1/documents` لإنشاء DOCX وXLSX وPPTX وCSV وTXT، مع اختبارات تلقائية.
- أُضيف موصل OpenAI Images API لتوليد الصور وتحرير الصور بجودة عالية قابلة للاختيار؛ يتطلب مفتاحاً آمناً في بيئة Backend ولم يُختبر بمفتاح إنتاجي بعد. لا يوجد حتى الآن موصل فيديو أو تكامل نشر اجتماعي أو WhatsApp أو اتصالات.
- PDF العربي مؤجل إلى أن تتوفر معالجة خطوط وتشكيل عربية موثوقة ويجتاز الملف اختبارات فتح وعرض.
- لا توجد بعد مصادقة إنتاجية أو تخزين سحابي دائم أو مهام خلفية موثوقة.

## التكلفة والخصوصية

يمكن تجهيز الكود والاختبارات داخل GitHub، لكن تشغيل بعض الميزات يتطلب لاحقاً مفاتيح مزودين أو موافقات OAuth أو استضافة أو رقم هاتف أو توقيع Apple. لا توضع أي أسرار في المستودع أو تطبيق الهاتف. لا تُفعّل خدمة مدفوعة أو اشتراك تلقائي دون موافقة صاحب المشروع.
