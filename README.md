# NIKO AI

**NIKO** مساعد شخصي متعدد اللغات والوسائط والمهارات، يُطوّر للـ **iPhone أولاً** مع إبقاء Android هدفاً تالياً من قاعدة Flutter مشتركة.

> **الحالة الحالية:** نموذج أولي قيد التطوير. توجد واجهة Flutter واتصال محلي بـ Ollama، وأساس أولي لتوليد مستندات Office والصور. لا توجد بعد مصادقة إنتاجية أو بنية تخزين متعددة المستخدمين أو تجربة صوت خلفية على iOS أو مولد فيديو إنتاجي.

## الرؤية

بناء مساعد شخصي بمستوى قدرات Tab AI: يفهم النص والصوت والصور والملفات، ويخطط وينفذ مهاماً متعددة الخطوات، وينشئ الصور والفيديو والمستندات، ويُنجز الأعمال عبر تكاملات رسمية. NIKO يستجيب لاسمه مباشرة دون Siri. لا تُعلن أي ميزة جاهزة إلا بعد اختبارها فعلياً.

## قرارات المنتج

- **iPhone أولاً:** تجربة صوتية أولاً، مع دراسة كلمة تنبيه NIKO مباشرة ضمن قيود iOS.
- **لا Siri:** لا نعتمد Siri أو App Intents أو Shortcuts كمسار تشغيل للمساعد.
- **Android لاحقاً:** نحافظ على التوافق بقاعدة Flutter مشتركة.
- **متعدد اللغات:** العربية بلهجاتها، والإنجليزية، والتركية، مع فهم المزج بينها.
- **خصوصية متعددة المستخدمين:** حساب مستقل لكل مستخدم وعزل بياناته عن بقية المستخدمين على مستوى API وقاعدة البيانات والملفات والمهام والذاكرة.
- **قابل للتوسع:** Backend عديم الحالة قدر الإمكان، تخزين مشترك آمن، Queue للمهام الطويلة، وحدود استخدام لكل حساب.
- **استقلالية مسؤولة:** تنفيذ المهام الآمنة دون أوامر تقنية متكررة، وطلب موافقة قبل الإرسال أو النشر أو الشراء أو الحجز أو الاتصال أو حذف البيانات.
- **واقعي تقنياً:** لا نعرض نتائج وهمية ولا ندّعي تشغيل خدمة قبل تهيئتها واختبارها.

## الحالة التنفيذية

- تطبيق Flutter أولي بواجهة محادثة وحفظ محلي وتفضيل لغة، واستوديو أولي للصور.
- Backend محلي متصل بـ Ollama للمحادثة.
- إنشاء أولي لـ DOCX وXLSX وPPTX وCSV وTXT.
- موصل OpenAI Images API للتوليد والتحرير، لكنه لم يُختبر بمفتاح إنتاجي.
- لا يوجد موصل فيديو إنتاجي، ولا مشروع iOS/Xcode متكامل في الفرع الذي جرى فحصه.
- CI موجود، وآخر تشغيل فحص معروف فشل بسبب مسار استيراد Python؛ إصلاحه قيد العمل.
- لا توجد بعد مصادقة إنتاجية أو تخزين سحابي دائم أو عزل متعدد المستخدمين أو مهام خلفية موثوقة.

## الخصوصية والأمان

كل مستخدم يجب أن يرى بياناته فقط. سيُفرض نطاق المستخدم على الخادم من جلسة مصادقة موثقة، وليس من معرّف يختاره تطبيق الهاتف. تشمل الحدود المحادثات والذاكرة والملفات والصور والفيديو والمهام والإعدادات. نحتاج تشفيراً أثناء النقل والتخزين، صلاحيات قاعدة بيانات، روابط ملفات قصيرة العمر، سجلات لا تحتوي محتوى خاصاً، وحدود استخدام ومراجعة أمنية واختبارات تمنع الوصول بين الحسابات.

لا نضع مفاتيح API أو رموز OAuth أو بيانات اعتماد في المستودع أو تطبيق الهاتف. لا تُفعّل خدمة مدفوعة أو اشتراك تلقائي دون موافقة صاحب المشروع. راجع [وثيقة الأمان متعددة المستخدمين](docs/SECURITY_PRIVACY_MULTI_TENANT.md).
