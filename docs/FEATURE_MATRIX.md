## تصنيف الأولوية
- **MVP:** ضروري لإثبات أن NIKO يعمل كمساعد مفيد وآمن.
- **لاحق:** يضاف بعد نجاح النسخة الأولى وتقييم التكلفة.
- **محدود/غير مضمون:** يخضع لقيود النظام أو موافقات طرف ثالث.
- **غير مضمون:** لا يجوز تسويقه كميزة مؤكدة قبل اختبار أو تغيير قيود المنصة.

## شرط قبول كل ميزة
قبل التنفيذ يجب توثيق:
1. هل تعمل على iOS وAndroid أم على منصة واحدة؟
2. هل تعمل دون إنترنت؟
3. هل تعمل عند إغلاق التطبيق أو قفل الهاتف؟
4. ما الأذونات المطلوبة؟
5. هل تستخدم خدمة خارجية أو ترسل بيانات إلى طرف ثالث؟
6. هل لها تكلفة تشغيل أو حدود استخدام؟
7. ما مستوى الموافقة المطلوبة؟
8. كيف نختبر النجاح والفشل؟
