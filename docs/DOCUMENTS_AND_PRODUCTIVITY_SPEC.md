# مواصفات المستندات والملفات والإنتاجية في NIKO

**الحالة:** مواصفات ومتطلبات قبول. دعم صيغة في واجهة المستخدم لا يعني أن القراءة أو التحرير أو التصدير مكتمل.
**الهدف:** إنشاء المستندات وفهم الملفات الموجودة وتعديلها مع الحفاظ على تنسيقها ومعلوماتها، مع دعم العربية وRTL والإنجليزية والتركية.

## 1. الصيغ المستهدفة

| الصيغة | إنشاء | قراءة/استخراج | تحرير/تحويل |
|---|---|---|---|
| DOCX | مطلوب | مطلوب | مطلوب |
| PDF | مطلوب | مطلوب | مطلوب ضمن الحدود الممكنة |
| XLSX | مطلوب | مطلوب | مطلوب |
| PPTX | مطلوب | مطلوب | مطلوب |
| TXT | مطلوب | مطلوب | مطلوب |
| CSV | مطلوب | مطلوب | مطلوب |
| الصور (PNG/JPEG/WebP) | عبر استوديو الصور | OCR/فهم الصورة | عبر استوديو الصور |

لا يُعلن دعم صيغة حتى توجد اختبارات فتح/قراءة/تعديل للمخرجات. يجب أن توضح الواجهة إذا كان PDF ممسوحاً ضوئياً أو محمياً أو غير قابل للتحرير مباشرة.

## 2. إنشاء المستندات

- إنشاء خطابات ورسائل وتقارير وسير ذاتية وعروض وجداول وخطط.
- دعم قوالب رسمية ومهنية قابلة للتخصيص.
- فصل المحتوى عن القالب حتى يمكن تغيير التصميم دون إعادة كتابة النص.
- دعم العربية والإنجليزية والتركية في المستند نفسه.
- دعم RTL للعربية مع ترتيب صحيح للعناوين والفقرات والجداول والقوائم والأرقام.
- اختيار حجم الصفحة والهوامش والخطوط والترويسات والتذييل والترقيم.
- معاينة قبل التصدير مع إمكانية تعديل النص أو طلب تعديلات محددة.
- حفظ نسخة قابلة للتحرير مع نسخة التصدير النهائية.

## 3. السيرة الذاتية والملفات المهنية

- استخراج بيانات CV من ملف يقدمه المستخدم.
- تنظيم الخبرات والتعليم والمهارات والشهادات والمشاريع والإنجازات.
- اقتراح صياغة احترافية دون تغيير الحقائق.
- عدم اختلاق مسميات وظيفية أو سنوات خبرة أو شهادات أو مهارات أو نتائج.
- تمييز الحقول الناقصة وطرح سؤال واحد عن المعلومة الأساسية.
- دعم ATS-friendly layout مع عدم ضمان اجتياز كل نظام ATS.
- إنشاء نسخ مختلفة لوظائف مختلفة مع الاحتفاظ بمصدر البيانات الأصلي.
- عرض كل تعديل جوهري للمستخدم قبل التصدير النهائي.

## 4. قراءة الملفات والاستيراد

- استيراد الملفات عبر iOS Files picker أو مشاركة الملف إلى NIKO.
- عرض اسم الملف ونوعه وحجمه قبل المعالجة.
- استخراج النص والجداول والعناوين والبيانات الوصفية حيثما تسمح الصيغة.
- OCR للمستندات والصور الممسوحة ضوئياً.
- تلخيص المستند والإجابة عن أسئلة محددة مع الإشارة إلى الصفحات/الأقسام.
- استخراج حقول منظمة إلى JSON/CSV/XLSX عند طلب المستخدم.
- المحافظة على ترقيم الصفحات ومراجع المصادر قدر الإمكان.
- رفض الملفات التالفة أو المشفرة التي لا يملك المستخدم صلاحية فتحها، وشرح ذلك بوضوح.

## 5. التحرير والتحويل

- تحرير موضعي يحافظ على بقية الملف، لا إعادة توليد المستند كله افتراضياً.
- عمليات مثل إعادة الصياغة، التصحيح، التلخيص، إعادة ترتيب الأقسام، find-and-replace، تحديث جدول أو شريحة.
- مقارنة قبل/بعد وإظهار ما تغير.
- تحويل بين الصيغ مع توضيح أي تنسيق قد لا ينتقل.
- لا يُدّعى الحفاظ على التنسيق بنسبة 100% دون اختبار.
- حماية الصيغ والمعادلات ومراجع الخلايا في XLSX.
- الحفاظ على ملاحظات المتحدث والروابط والصور في PPTX متى أمكن.

## 6. الأمان ومعالجة الملفات

- حدود حجم وعدد صفحات/شرائح/صفوف قابلة للضبط على الخادم.
- فحص MIME وتوقيع الملف الفعلي، وليس الامتداد فقط.
- رفض الملفات التنفيذية أو المضغوطة غير المسموح بها.
- تشغيل parsers/OCR في workers معزولة بمهلة وحدود ذاكرة/CPU.
- حماية من zip bombs وXML external entities وpath traversal وmalicious macros.
- عدم تشغيل macros أو محتوى نشط من الملفات.
- تخزين خاص، وتحقق ملكية قبل كل قراءة أو تعديل أو تنزيل أو حذف.
- روابط تنزيل موقعة قصيرة العمر، لا روابط عامة دائمة.
- عدم تسجيل نص المستند أو بياناته الشخصية في logs.
- حذف الملفات ومخرجاتها ونسخ OCR/embeddings المرتبطة بها وفق سياسة معلنة.

## 7. تجربة المستخدم على iPhone

- اختيار ملف من Files أو مشاركة الملف إلى NIKO.
- رفع يظهر تقدماً حقيقياً وإمكانية إلغاء.
- شاشة معاينة قبل وبعد، مع عرض اسم الصيغة والحجم.
- حفظ إلى Files أو مشاركة عبر ورقة مشاركة iOS بعد طلب المستخدم.
- لا يتم إرسال ملف إلى بريد أو منصة خارجية دون موافقة.
- دعم RTL في واجهة المعاينة ومحرر النص.
- التعامل مع ملفات كبيرة ومقاطعة التطبيق واستعادة حالة المهمة.

## 8. معايير الاختبار

### صلاحية المخرجات
- إنشاء DOCX وPDF وXLSX وPPTX وTXT وCSV.
- فتح الملفات الناتجة بمكتبات parser مستقلة أو أدوات تحقق.
- اختبار الجداول والصيغ والخطوط والروابط والصور.
- اختبار العربية وRTL والنص المختلط والأرقام.
- اختبار المستندات الطويلة والملفات الفارغة والملفات غير الصالحة.

### صحة المحتوى
- عدم اختلاق معلومات في CV.
- عدم إسقاط أرقام/تواريخ/أسماء مهمة عند التلخيص.
- ربط الإجابات بالصفحات أو المقاطع الصحيحة.
- قياس جودة OCR منفصلة حسب اللغة ونوع الصورة.

### الأمان
- مستخدم آخر لا يستطيع الوصول إلى الملف أو ناتج OCR أو التنزيل.
- انتهاء صلاحية signed URL.
- رفض الملفات الضارة أو التي تتجاوز الحدود.
- لا يتم تشغيل محتوى نشط من الملفات.
- حذف الملف يزيل النسخ المرتبطة وفق سياسة الاحتفاظ.

## 9. تعريف الإنجاز

تعد الصيغة مدعومة عندما تنجح اختبارات إنشاء/قراءة/تحرير/فتح المخرجات حسب الوظائف التي تعلنها الواجهة، مع اختبارات RTL والأمان. لا يكفي وجود دالة توليد أو mock أو endpoint لإعلان دعم كامل.
