# سجل قرارات المشروع

هذا السجل يوثق القرارات والافتراضات. القرار المقترح لا يصبح نهائياً إلا بعد مراجعته واعتماده.

| الموضوع | القرار / التوجه الحالي | الحالة |
|---|---|---|
| اسم المشروع | NIKO AI | معتمد مبدئياً |
| طبيعة المنتج | مساعد شخصي عام متعدد المنصات | توجه معتمد |
| اللغات الأساسية | العربية والإنجليزية والتركية | متطلب |
| اللهجات | فهم اللهجات العربية والتبديل والمزج بينها | متطلب يحتاج اختباراً |
| أسلوب الرد | يتكيّف مع لغة ولهجة المستخدم | متطلب |
| الصوت | صوت رجولي عند توفر خيار مناسب | متطلب |
| الميزانية | صفر ريال مستهدف | قيد أساسي |
| الأولوية التقنية | مفتوح المصدر ومحلي أولاً | توجه |
| التطبيق | iOS وAndroid | هدف |
| ترتيب التنفيذ | التطبيق الأساسي أولاً، ثم التكاملات الخارجية تدريجياً | وافق عليه صاحب المشروع |
| نطاق MVP | محادثة ولغات وصوت داخل التطبيق ومهام محلية وذاكرة اختيارية وأمان | مقترح بانتظار اعتماد التفاصيل |
| WhatsApp | تكامل رسمي في مرحلة لاحقة بعد التحقق من التكلفة | مؤجل للدراسة |
| كلمة التنبيه على iOS | لا ضمان للاستماع الدائم؛ دراسة اختصارات النظام | قيد موثق |
| Backend | يؤجل حتى تثبت الحاجة ووجود استضافة مناسبة | غير محسوم |
| إطار الهاتف | Flutter مرشح | غير معتمد نهائياً |
| Backend | FastAPI مرشح | غير معتمد نهائياً |

## سجل التغييرات
- 0.1: إنشاء وثائق التأسيس الأولى.
- 0.2: توثيق موافقة صاحب المشروع على ترتيب التنفيذ: التطبيق الأساسي أولاً، والتكاملات لاحقاً.
