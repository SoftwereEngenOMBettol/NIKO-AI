# NIKO Skills

كل مهارة وحدة مستقلة توضح:
- اسم المهارة ووظيفتها.
- المدخلات والمخرجات.
- الصلاحيات المطلوبة.
- هل تتصل بالإنترنت أو بخدمة خارجية؟
- مستوى المخاطر والموافقة المطلوبة.
- التكلفة وحدود الاستخدام.
- حالات الفشل وطريقة إبلاغ المستخدم.

تبدأ المهارات الأولى بالعمليات المحلية منخفضة المخاطر. لا تنفذ المهارات الخارجية إجراءات حساسة دون موافقة مناسبة.

لا توجد مهارات تنفيذية في هذه المرحلة.
