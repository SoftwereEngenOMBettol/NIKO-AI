# AI Engine

الوحدة المخصصة لمنطق NIKO الأساسي: تحليل الطلبات، اكتشاف اللغة واللهجة، تخطيط المهام، اختيار النموذج، وإدارة تنفيذ المهارات.

يجب تصميم واجهة موحدة لمزودي النماذج حتى يمكن استبدال النموذج المحلي أو الخارجي دون إعادة بناء التطبيق.

لا يوجد نموذج أو كود ذكاء اصطناعي معتمد في هذه المرحلة.
