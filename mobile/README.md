# تطبيق NIKO للهاتف

تطبيق Flutter متعدد المنصات، **يُطوّر ويُختبر للـ iPhone أولاً**. يبقى Android هدفاً لاحقاً من قاعدة الكود نفسها.

## ما تم بناؤه
- واجهة محادثة عربية باتجاه RTL.
- مظهر داكن أولي وهوية بصرية تجريبية لـ NIKO.
- عرض اللغات المستهدفة: العربية والإنجليزية والتركية.
- إرسال الرسائل وعرضها محلياً داخل واجهة تجريبية.
- حفظ سجل المحادثة على الجهاز باستخدام SharedPreferences.
- مسح سجل المحادثة بعد تأكيد المستخدم.
- طبقة مستقلة قابلة للاستبدال لمحرك المحادثة.
- اختيار لغة الرد: تلقائي أو العربية أو الإنجليزية أو التركية، مع حفظ الاختيار محلياً.
- مؤشر انتظار أثناء تجهيز الرد.
- اختبارات أولية للواجهة والخدمة التجريبية.

## ما لم يُربط بعد
- لا يوجد نموذج ذكاء اصطناعي متصل حتى الآن؛ `DemoNikoChatService` يعرض رسالة توضيحية فقط حسب اللغة المختارة.
- زر الصوت يعرض تنبيهاً بأن ميزة الصوت قيد التطوير، ولا يسجل الصوت بعد.
- حفظ المحادثة محلي فقط؛ لا توجد مزامنة سحابية أو ذاكرة دلالية للحقائق الشخصية.
- لا توجد مهارات أو إشعارات في هذه النسخة.
- اختيار اللغة لا يعني أن فهم اللهجات أو اكتشاف اللغة تلقائياً يعملان بالفعل.

## أولوية المنصات
1. iOS: واجهة وتجربة وأذونات وصوت وخصوصية واختبارات iPhone أولاً.
2. Android: الحفاظ على قابلية البناء من قاعدة Flutter نفسها، ثم استكمال الاختبارات والتحسينات الخاصة بعد استقرار iOS.

## التطوير والبناء
### على Windows
يمكن تطوير Dart/Flutter وتشغيل التحليل والاختبارات. Android Emulator متاح كاختبار ثانوي، لكنه ليس بوابة قبول المنتج الأولى.

```powershell
cd mobile
flutter pub get
flutter analyze
flutter test
```

### بناء iOS
- يتطلب بناء iOS وتشغيل Simulator وجود macOS وXcode.
- تم التحقق بنجاح من بناء iOS Simulator عبر GitHub Actions على macOS.
- ملف المحاكي الناتج محفوظ كـ artifact باسم `niko-ai-ios-simulator` لمدة 14 يوماً من وقت كل تشغيل ناجح.
- نسخة Simulator ليست IPA ولا يمكن تثبيتها على iPhone الحقيقي.
- تثبيت التطبيق على iPhone يحتاج بناءً موقعاً وشهادات وإعدادات Apple المناسبة.
- يضبط مسار CI اسم العرض إلى `NIKO`، بينما تظل هوية Bundle النهائية بحاجة إلى اعتماد قبل التوزيع.

### بناء Android لاحقاً
يوجد workflow منفصل يمكن تشغيله يدوياً لبناء APK عند الحاجة، لكنه لم يعد يُشغّل مع كل تغيير؛ لأن الأولوية الحالية لبناء iOS.

## ملاحظات
- لا تضع مفاتيح API أو كلمات مرور داخل التطبيق أو المستودع.
- يجب اختبار أي ميزة تعتمد على صلاحيات النظام على iPhone فعلي قبل اعتبارها جاهزة.
