# تطبيق NIKO للهاتف

تطبيق Flutter متعدد المنصات، **يُطوّر ويُختبر للـ iPhone أولاً**. يبقى Android هدفاً لاحقاً من قاعدة الكود نفسها.

## ما تم بناؤه
- واجهة محادثة عربية باتجاه RTL وهوية بصرية داكنة أولية.
- إدخال نصي وصوتي وإخراج صوتي عند الطلب.
- حفظ المحادثة محلياً وإعداد لغة الرد.
- عميل API للاتصال بمحرك NIKO المحلي مع رسائل أخطاء واضحة.
- اختيار اللغة تلقائياً أو العربية أو الإنجليزية أو التركية.

## محرك المحادثة
- التطبيق يتصل بخادم FastAPI محلي، والخادم يتصل بنموذج Ollama على كمبيوتر المستخدم.
- النموذج الافتراضي `qwen2.5:3b`؛ يعمل محلياً دون مفتاح API، لكن الأداء يعتمد على الجهاز وقد يكون بطيئاً على CPU.
- اتبع `backend/README.md` لتثبيت النموذج وتشغيل الخادم.
- Android Emulator يستخدم `http://10.0.2.2:8000` افتراضياً. يمكن تغيير العنوان باستخدام `--dart-define=NIKO_API_BASE_URL=...`.
- الكمبيوتر يجب أن يبقى مشغلاً ومتصلًا بالشبكة أثناء استخدام هذا المحرك.

## الصوت واللغات
- الإدخال الصوتي يستخدم `speech_to_text` ويضع النص في حقل الرسالة قبل الإرسال.
- الإخراج الصوتي يستخدم أصوات النظام عبر `flutter_tts` ويحاول اختيار صوت رجولي عند توفره.
- فهم اللهجات واكتشاف اللغة مسؤولية النموذج، ويحتاج إلى تقييم فعلي على أمثلة عُمانية وخليجية ومختلطة. لا نضمن دقة كاملة من أول نموذج.

## أولوية المنصات
1. iOS: معيار تصميم المنتج واختباره.
2. Android: اختبار توافق ثانوي من قاعدة Flutter المشتركة.

## الاختبار على Windows
```powershell
cd mobile
flutter pub get
flutter analyze
flutter test
flutter run -d emulator-5554 --dart-define=NIKO_API_BASE_URL=http://10.0.2.2:8000
```

قد يتطلب Android أثناء التطوير السماح باتصالات HTTP المحلية في `AndroidManifest.xml`؛ راجع `backend/README.md`. لا تستخدم HTTP في إصدار إنتاجي.

## ما لم يُنجز بعد
- ذاكرة محادثة متعددة الأدوار على الخادم ومزامنة اختيارية.
- نشر آمن عبر HTTPS ومصادقة وحماية المعدل.
- اختبار iPhone فعلي وإعداد صلاحيات الشبكة المحلية وATS.
- اختبارات منهجية للهجات والخلط بين العربية والإنجليزية والتركية.
- لا توجد تكاملات WhatsApp أو LinkedIn أو Instagram.
