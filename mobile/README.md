# تطبيق NIKO للهاتف

هذا المجلد يحتوي على تطبيق NIKO الأولي باستخدام Flutter.

## ما تم بناؤه
- واجهة محادثة عربية باتجاه RTL.
- مظهر داكن أولي وهوية بصرية تجريبية لـ NIKO.
- عرض اللغات المستهدفة: العربية والإنجليزية والتركية.
- إرسال الرسائل وعرضها محلياً داخل واجهة تجريبية.
- حفظ سجل المحادثة على الجهاز باستخدام SharedPreferences.
- مسح سجل المحادثة بعد تأكيد المستخدم.
- طبقة مستقلة قابلة للاستبدال لمحرك المحادثة.
- اختيار لغة الرد: تلقائي أو العربية أو الإنجليزية أو التركية، مع حفظ الاختيار محلياً.
- مؤشر انتظار أثناء تجهيز الرد.
- اختبارات أولية للواجهة.

## ما لم يُربط بعد
- لا يوجد نموذج ذكاء اصطناعي متصل حتى الآن؛ `DemoNikoChatService` يعرض رسالة توضيحية فقط حسب اللغة المختارة. واجهة `NikoChatService` جاهزة لاستبداله بمزود حقيقي بعد اعتماد المحرك.
- زر الصوت يعرض تنبيهاً بأن ميزة الصوت قيد التطوير، ولا يسجل الصوت بعد.
- حفظ المحادثة محلي فقط؛ لا توجد مزامنة سحابية أو ذاكرة دلالية للحقائق الشخصية.
- لا توجد مهارات أو إشعارات في هذه النسخة.
- اختيار اللغة لا يعني أن فهم اللهجات أو اكتشاف اللغة تلقائي يعملان بالفعل؛ هذه القدرات تحتاج محرك ذكاء اصطناعي واختبارات لغوية.

## التشغيل المحلي
بعد تثبيت Flutter:

```powershell
cd mobile
flutter pub get
flutter run
```

## بناء Android
يحتوي المستودع على GitHub Actions workflow لبناء APK في السحابة عند تحديث ملفات `mobile/` على فرع `main` أو عند تشغيل workflow يدوياً.

بعد نجاح البناء، يمكن تنزيل الملف من:
GitHub → Actions → Build NIKO Android APK → Artifacts.

لا يتطلب مسار البناء السحابي تثبيت Android Studio على جهاز التطوير.

## ملاحظات
- بناء iOS وتوقيعه يحتاجان macOS وXcode في مرحلة الاختبار والإصدار.
- لا تضع مفاتيح API أو كلمات مرور داخل التطبيق أو المستودع.
